# Documentary assets

- **Kanaa generated whoosh** (`backend/app/services/sound_effect_service.py`, `make_whoosh`): original procedural audio, generated locally. Released under CC0 1.0 Universal for use in Kanaa and exported videos. No third-party recording is bundled or downloaded.
- **Natural Earth** country and state outlines: public domain, https://www.naturalearthdata.com/about/terms-of-use/ . Documentary maps reuse the data already installed by Travel map; no download is initiated by a graphic.
- **GeoNames** place lookup data used by Travel map: CC BY 4.0, https://www.geonames.org/ . Documentary graphic coordinates are supplied by the user and do not require this dataset.
